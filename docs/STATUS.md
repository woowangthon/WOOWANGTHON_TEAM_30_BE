## 알려진 한계

- **lite 토크나이저**(Render 무료)는 kiwi보다 덜 정확합니다(골든 세트 1문항 차이). 유료 인스턴스에서는 `YEOUN_TOKENIZER=kiwi` 권장.
- 키가 없으면 올린 녹음의 자막이 비어 있어(지어내지 않으려고) 직접 적기 전까지는 검색되지 않습니다. 미리 남기기 녹음은 질문으로 찾아집니다.
- 화자 분리가 없으면(none) 파일 전체가 한 목소리로 묶여, 다른 사람의 말은 클립별로 빼야 합니다.
- 레이트 리밋·로그인 시도 제한은 메모리 기반이라 API 인스턴스가 하나일 때만 정확합니다.
- DB는 Neon 무료 PostgreSQL(만료 없음, 프로젝트당 1GB, 한 달 100 CU-시간, 5분 쉬면 잠듦). Render 무료 DB는 작업 공간당 1개라 쓰지 않음.
