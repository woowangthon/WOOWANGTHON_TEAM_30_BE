# 여운 개인정보 처리방침 (초안)

> **이 문서는 친구 테스트(staging)용 초안이에요.** 정식 서비스를 열기 전에 반드시 법률 전문가의 검토를 받아 고쳐야 해요.
> 내용은 현재 코드가 실제로 하는 일을 기준으로 썼어요. 코드와 다른 점을 발견하면 이 문서를 먼저 고쳐 주세요.

- 시행일: `[YYYY년 MM월 DD일 — 정식 공개 전 정하기]`
- 운영자: `[팀 이름]`
- 문의: `[이메일 주소]` (삭제 요청·개인정보 문의)

---

## 1. 여운이 하는 일

여운은 소중한 사람의 **실제 목소리 녹음**을 모아 정리하고, 가족이 메시지를 보내면 녹음에 있는 말은 **실제로 했던 말(원본 녹음 클립)** 로 들려주고, 녹음에 없는 말은 그 사람 말투로 짧은 글 답장을 만들어 **'AI가 만든 말'** 로 표시하는 추억 보관 서비스예요.

- 그 사람의 목소리를 **합성하지 않아요.** 음성 합성(TTS)과 목소리 복제 기능이 없어요.
- AI는 녹음 가운데 무엇을 들려 드릴지 고르고, 녹음에 없는 말에는 그 사람 말투로 짧은 글 답장을 만들어요. 만든 답장은 'AI가 만든 말'로 표시하고, 근거가 된 실제 녹음을 함께 보여 드려요. 근거가 없거나 유언·돈·의료·법률처럼 그분이 대신 답할 수 없는 이야기면 답장을 만들지 않아요.

## 2. 모으는 개인정보

| 구분 | 항목 | 어디에 저장하나요 |
|---|---|---|
| 계정 | 이메일, 부르는 이름, 비밀번호 | 비밀번호는 원문을 저장하지 않고 **argon2 해시**로만 저장 |
| 로그인 | 세션 토큰 | 서버에는 토큰의 **sha256 해시**만 저장, 브라우저에는 HttpOnly 쿠키 |
| 추억 공간 | 그분의 이름(부르는 말), 관계, 생일, 기일, 메모 | DB |
| 올린 자료 | 녹음·영상·사진 **원본 파일**, 원본에서 자른 **클립**, 사진 미리보기 | 저장소(아래 4장) — **암호화** |
| 자료에서 만든 정보 | 받아쓴 **자막**(원래 자막·고친 자막), 화자 구분, **태그**, 검색용 **토큰**, (외부 임베딩 키가 있을 때만) **임베딩 벡터**, 파일명, 녹음 날짜, 길이 | DB |
| 말투 요약 | 그분 녹음 자막에서 뽑은 부르는 말·자기 호칭·어미·자주 쓰는 표현(최대 8개)·주제 | **서버 메모리에만** 잠시(DB에 저장하지 않음) |
| 미리 남기기 | 녹음하는 분의 **음성**, 질문, 녹음 링크의 **동의 시각** | 저장소(암호화) + DB |
| 가족 초대 | 초대받은 가족의 계정, 권한(소유자·편집·보기) | DB |
| 이용 기록 | **하루 대화 횟수**(제한을 위해 숫자만), 즐겨찾기, 닫은 알림 | DB |

**저장하지 않는 것**

- **대화 내용**(내가 보낸 말, 돌아온 답)은 서버에 저장하지 않아요. 내 브라우저 탭(sessionStorage)에만 잠시 남고, 탭을 닫으면 사라져요.
- **음성으로 말 걸기** 녹음은 글자로 바꾼 뒤 바로 지워요(서버 임시 폴더에서만 처리).
- 녹음 링크·초대 링크의 **토큰 원문**은 저장하지 않아요(해시만).

## 3. 쓰는 목적

1. 올린 분과 초대받은 가족이 그분의 실제 목소리를 정리하고, 다시 찾아 듣게 하기
2. 받아쓰기·목소리 나누기·주제 태그·검색으로 원하는 녹음을 찾게 하기
3. 마음 돌봄: 대화에서 자살·자해 위험 신호가 보이면 도움 안내(109, 1577-0199)를 먼저 보여 주기
4. 계정 관리, 부정 사용 방지(로그인 시도 제한, 하루 대화 횟수 제한)
5. 메시지를 보내면 녹음에 기대어 그분 말투로 짧은 답장을 만들고, 'AI가 만든 말'로 표시해 근거 녹음과 함께 보여 주기

다음 목적으로는 **쓰지 않아요**: 광고, 판매, 우리 회사의 AI 모델 학습, 그분의 목소리 합성.

## 4. 보관 위치와 보호 조치

- **봉투 암호화**: 공간마다 무작위 데이터 키(32바이트)를 만들고, 이 키를 서버의 마스터 키(`YEOUN_MASTER_KEY`)로 감싸 저장해요. 모든 파일은 공간 데이터 키로 **AES-256-GCM** 암호화하고, 저장 위치를 함께 묶어(AAD) 다른 위치로 옮기거나 바꾸면 풀리지 않아요.
- **재생은 서명 링크로만**: 녹음·사진은 **15분 뒤 만료**되는 서명 URL로만 열려요. 링크를 바꾸면 열리지 않아요.
- **저장소 종류**(운영자가 설정)
  - 친구 테스트(Render 무료): PostgreSQL 데이터베이스 안에 암호화된 바이트로 저장(`YEOUN_STORAGE=db`), 파일 25MB·공간 150MB 상한
  - 개발: 서버 디스크(`local`)
  - 실사용: S3 호환 저장소(예: Cloudflare R2, `s3`). 저장소 업체는 암호화된 내용만 가지고 있어요.
- **접근 통제**: 공간은 올린 분과 초대받은 가족만 볼 수 있어요. 다른 사람에게는 공간이 있는지조차 보이지 않아요(404). 샘플 공간만 가상 인물이라 누구나 읽을 수 있어요.
- **로그**: 서버 로그에는 요청 경로 틀(`/api/spaces/{space_id}/clips`)과 오류 코드만 남기고, **자막·파일명·보낸 말·토큰·API 키는 남기지 않아요**(가림 필터로 한 번 더 확인).
- **CSRF·쿠키**: 쿠키는 HttpOnly·SameSite=Lax·(HTTPS에서) Secure, 쓰기 요청은 전용 헤더가 있어야 받아요.

## 5. 보관 기간과 삭제

| 무엇을 지우면 | 함께 지워지는 것 | 언제 |
|---|---|---|
| 자료 하나 | 원본 파일, 클립, 미리보기, 자막, 태그, 검색 색인, 처리 작업 기록, 즐겨찾기 | 바로 |
| 추억 공간 | 위 모든 것 + 가족 권한, 초대·녹음 링크, 클립 모음, **공간 데이터 키** | 바로 (말투 요약은 서버 메모리에만 있어 서버가 다시 시작될 때 사라져요) |
| 계정 | 내가 만든 모든 공간(위와 같음) + 계정·세션 | 바로 (초대받은 남의 공간은 그대로) |

- 지우기 전에 **전체 내보내기**(zip: 원본 + `자막.json`)를 할 수 있어요.
- 호스팅·데이터베이스 업체(Render 등)가 자체적으로 만드는 백업이나 로그는 **그 업체의 정책**에 따라 일정 기간 남을 수 있어요. 다만 공간을 지우면 그 공간의 **데이터 키가 함께 사라지기 때문에**, 백업에 암호화된 파일이 남아 있어도 다시 풀 수 없어요(crypto-shredding).
- 친구 테스트 기간이 끝나면 운영자는 테스트 데이터베이스를 지우고, 그 사실을 참여자에게 알려요. `[테스트 종료 예정일]`

## 6. 외부 처리 위탁

AI 기능은 운영자가 API 키를 넣었을 때만 외부 서비스로 가요. 키가 없으면 여운 서버 안의 규칙 기반 방식으로 처리하고 아무것도 밖으로 보내지 않아요. 각 공간의 **설정 → 외부 서비스**에서 지금 무엇이 쓰이는지 볼 수 있어요.

| 업체 | 하는 일 | 보내는 데이터 | 학습에 쓰나요 | 보관 (업체 정책) |
|---|---|---|---|---|
| 충북대 NOVA API Gateway (운영: 마인드로직) → Soniox·Anthropic·OpenAI | 받아쓰기·목소리 나누기(Soniox), 의도 파악·녹음 고르기·주제 태그·말투 요약·답장 만들기·내용으로 목소리 나누기(Anthropic Claude), 임베딩(OpenAI) | 오디오, 보낸 말, 최근 대화 기록(최대 8개), 그분 녹음 자막(말투 요약용 최대 80개, 답장 근거용 최대 12개), 내용으로 목소리를 나눌 때의 자막 문장, 후보 클립의 자막·날짜·태그 | 게이트웨이와 각 제공사 API 정책을 따름 `[확인 필요]` | 받아쓰기 결과·업로드 오디오는 처리 뒤 최대 1시간 보관 후 삭제(게이트웨이 문서). 그 밖은 각 사 정책 `[확인 필요]` |
| OpenAI | 받아쓰기(whisper-1), 목소리 나누기, 임베딩 | 오디오, 자막 텍스트·보낸 말 | 쓰지 않음(기본 설정) | 오남용 감시를 위해 최대 30일 보관 후 삭제 |
| Anthropic | 의도 파악, 녹음 고르기, 주제 태그, 말투 요약, 답장 만들기, 내용으로 목소리 나누기, 위험 신호 판단(규칙보다 높일 때만) | 보낸 말, 최근 대화 기록(최대 8개), 그분 녹음 자막(최대 80개), 후보 클립의 자막·날짜·태그 | 쓰지 않음(기본 설정) | 공급자 정책에 따라 일정 기간 보관 후 삭제 |
| Google (Gemini) | 받아쓰기·LLM·임베딩 중 운영자가 고른 것 | 위와 같음 | **무료 등급은 학습·사람 검토에 쓰일 수 있음** / 유료 등급은 쓰지 않음 | 무료: 구글 정책 / 유료: 오남용 감시를 위해 일정 기간 |
| Render | 서버·데이터베이스 호스팅 | 모든 데이터(파일은 암호화된 상태) | — | 서비스 이용 기간 + 업체 백업 정책 |
| Cloudflare R2 (선택) | 파일 저장 | 암호화된 파일 | — | 우리가 지울 때까지 |

**학습에 쓰는 무료 등급 정책**

- 정식 서비스(`production`)에서는 실제 사용자 자료에 **쓰지 않아요.**
- 친구 테스트(`staging`)에서는 공간 소유자가 계정 설정에서 안내를 읽고 **동의한 경우에만** 써요. 동의하지 않아도 모든 기능을 기본 방식으로 쓸 수 있어요.
- 가상 인물로 만든 샘플 공간에는 이 제한이 없어요(실제 사람의 정보가 아님).

## 7. 함께 녹음된 다른 사람

통화 녹음과 영상에는 그분과 대화한 **다른 사람의 목소리**가 들어 있을 수 있어요.

- 자료를 올릴 때 다음 문구를 확인받아요: **"이 자료를 올릴 권리가 있고, 함께 나온 사람의 뜻을 존중합니다."**
- **목소리 확인** 단계에서 녹음마다 목소리를 나눠 들려 드리고, 그분이 아닌 목소리는 **대화에 쓰지 않도록** 고를 수 있어요(클립 하나씩 빼기도 가능).
- 함께 녹음된 분이 삭제를 원하면 공간 소유자에게, 또는 운영자 연락처로 알려 주세요.

## 8. 미리 남기기 녹음하는 분

녹음 링크를 받은 분(주로 부모님)은 로그인 없이 녹음하고, 녹음을 시작하기 전에 아래 문구를 보고 **동의**해야 녹음을 보낼 수 있어요. 동의 시각을 저장해요.

> 이 녹음은 {보낸 분}님의 '여운' 추억 공간에 원본 그대로 보관돼요. {보낸 분}님과 {보낸 분}님이 초대한 가족만 들을 수 있어요. 여운은 이 목소리로 새 음성을 만들지 않아요. 다만 가족이 메시지를 보내면 녹음에 남은 말투를 참고해 글로 답장을 만들 수 있고, 그 답장에는 'AI가 만든 말'이라는 표시가 붙어요. 나중에 찾기 쉽도록 녹음을 글자로 옮기는 데 음성 인식 서비스를 쓸 수 있어요. 원하시면 언제든 보낸 분께 지워 달라고 하실 수 있어요.

- 링크는 정해진 기간(기본 7일, 최대 30일) 뒤 만료되고, '다 했어요'를 누르면 다시 쓸 수 없어요(1회용).
- 한 번에 최대 5분까지 녹음돼요.

## 9. 떠난 분의 정보에 대해

법적으로 돌아가신 분의 정보는 살아 있는 사람의 개인정보와 보호 범위가 다를 수 있어요. 그래도 여운은 **떠난 분의 목소리와 이야기도 개인정보와 같은 수준으로** 보호해요. 또 유족 자신의 정보와 녹음에 함께 나온 사람의 정보는 개인정보로 다뤄요. `[법률 검토 필요: 고인 정보·유족 권리 관련 문구]`

## 11. 만 14세 미만

여운은 **만 14세 미만 아동의 가입을 받지 않아요.** 만 14세 미만으로 확인되면 계정과 자료를 지워요. `[법정대리인 동의 절차를 둘지 법률 검토]`

## 12. 쿠키

로그인 유지를 위한 세션 쿠키(`yeoun_session`) 하나만 써요. 광고·분석 쿠키는 쓰지 않아요. 큰 글씨 설정과 오래 머문 시간(쉬어 가기 안내)은 내 브라우저 저장소에만 남아요.

## 13. 바뀌는 경우
