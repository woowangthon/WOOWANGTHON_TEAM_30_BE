## 2026-11-14

### 기억 대화 (메신저형)
- `POST /api/spaces/{id}/talk`: 그분 녹음 12개와 말투 카드로 답장 하나. 원본 녹음 그대로(original) / 'AI가 만든 말' + 근거 녹음 1~3개(generated) / 여운 안내(guide) / 위기 전환(crisis). 유언·돈·용서·의료·법률은 답하지 않는다. (PR #5)
- 기억책·기억 통화를 넣었다가(PR #4) 같은 날 우왕톤 범위에서 빼고 `0003_drop_books`로 표를 지웠다.
- 목소리가 하나로 나온 통화·영상은 LLM이 내용으로 두 사람 나누기, 그분을 부르는 말('엄마, …')은 그분 말로 쓰지 않기. (PR #5)
- 원칙 테스트가 `speaker_split` 모듈 이름과 `/speakers/` 주소의 `speak`에 걸리던 것을 고침(모듈 이름 `content_split`, 패턴 `speak(?!er)`). (PR #7)
- 기억 대화 보강: 답장 LLM이 위험도도 판단(규칙보다 높일 때만), 경험·사실·조언 답은 관련 녹음이 근거에 있어야 내보냄, 호칭 오해 프롬프트 수정. 배포본에서 새 위기 문장 0/10 → 10/10, 녹음에 없는 질문 안내 2/4 → 4/4. (PR #10)
- 위기 규칙 넓힘: 기억 대화 검증에서 놓친 "더는 못 살겠어", "손목을 그었어", "수면제를 한꺼번에", "그만 살고 싶어"를 잡도록 조사·활용형 추가(테스트 5개 추가). 규칙 수정 뒤 새로 쓴 위기 문장 10개로 따로 재어 한계를 기록. (PR #9)
- 문서를 기억 대화 기준으로 고침(README 원칙, STATUS, GENAI_USAGE, privacy, decisions D27~D30), 미리 남기기 동의 문구에 'AI가 만든 말' 안내 추가, 기억 대화 평가 도구 `python -m app.eval_talk` 추가.

## 2026-11-09

### 1단계 — 스키마·뼈대·make 명령
- 공통 스키마 `shared/schema.json`과 코드 생성기(`make gen`): Pydantic 모델·TS 타입 자동 생성.
- 서버 뼈대: FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, 설정(YEOUN_ 접두사만 읽음), 공통 오류 형식, 로그 가리기.
- 계정: 이메일+비밀번호(argon2) 가입·로그인, 세션 쿠키, CSRF 헤더 검사, staging 초대 코드.
- 추억 공간 만들기·고치기·삭제(이름 확인), 공간별 데이터 키 봉투 암호화.
- 웹 뼈대: Next.js 15 + Tailwind 4, `/api` rewrites, 잠든 서버 자동 재시도 클라이언트와 안내 배너, web 시작 때 API 깨우기.
- `make dev / test / e2e / seed / eval / lint / gen` 명령.

### 2단계 — 자료 올리기·처리 파이프라인
- 음성(m4a·mp3·wav·aac·amr·ogg)·영상(mp4·mov)·사진(jpg·png·heic) 여러 개 올리기, 진행률·실패 재시도, 권리 동의 확인.
- 처리 단계 표시: 소리 정리(16kHz mono) → 받아쓰기 → 목소리 나누기 → 문장 클립(2~30초) → 주제 붙이기 → 찾기 준비.
- AI 어댑터(mock·실제 공급자·auto)와 '학습에 쓰는 무료 등급' 정책. 키가 없어도 전체 흐름이 돈다.
- 파일은 공간별 키로 AES-GCM 암호화 저장, 서명 URL로만 재생(사파리용 Range 지원).
- 기종별 녹음 찾는 법 안내(갤럭시·아이폰·카카오톡·동영상·예전 휴대폰).

### 3단계 — 목소리 확인
- 녹음마다 화자별 대표 구간을 들려주고 "이 목소리가 누구예요?"를 고른다. 그 사람 목소리 클립만 대화에 쓴다.
- 화자 분리가 없으면 파일 단위로 고르고, 클립별 포함/제외·자막 고치기(고치면 바로 다시 색인).

### 4단계 — 원본 기반 대화
- 말을 걸면 ① 위기 신호 → ② 의도·키워드 → ③ BM25(+임베딩) 후보 20개 → ④ LLM이 최대 3개 고르기 → ⑤ 클립 카드 + 여운 안내.
- LLM 출력 검증: 후보 밖 ID·지어낸 인용·'엄마: …' 같은 대사 형식은 버린다. 실패하면 규칙 기반으로 계속 답한다.
- 맞는 녹음이 없으면 "딱 맞는 녹음은 없어요"와 가까운 추억. 그 사람이 아닌 목소리는 절대 쓰지 않는다.
- 음성으로 말 걸기(받아쓰기만, 저장 안 함), 즐겨찾기, 하루 대화 횟수 제한(staging).

### 5단계 — 추억 타임라인·미리 남기기
- 타임라인: 날짜별 클립과 사진, 주제 필터, 즐겨찾기, '지난해 오늘'.
- 미리 남기기: 한국어 질문 카드 72개(9개 묶음) + 직접 쓰는 질문. 로그인 없이 쓰는 녹음 링크(만료·1회용, 서버엔 토큰 해시만).
- 녹음하는 쪽 화면: 큰 글씨·큰 버튼, 동의 문구 먼저, 녹음·다시 듣기·다시 하기·보내기·다 했어요.
- 녹음은 원본 클립으로 저장되고 질문과 연결되어, 자막이 없어도 질문 낱말로 찾을 수 있다.

### 6단계 — 보안·삭제·내보내기
- 공간·자료·계정 완전 삭제(파일, 자막, 색인, 작업 기록, 링크, 즐겨찾기까지) 테스트.
- 암호화 테스트: 다른 공간 키·다른 위치·변조된 파일은 풀리지 않음, 운영 환경은 마스터 키 필수.
- 전체 내보내기(zip: 원본 + 자막.json).
- 외부 서비스 목록(보내는 데이터·학습 사용·보관)과 보관 기간 안내.
- 가족 초대(P1): 소유자/편집/보기 권한, 1회용 초대 링크. 권한 표 테스트(남의 공간은 존재도 알 수 없음).
- 로그에 자막·파일명·토큰이 남지 않는지 테스트. YEOUN_ 접두사 변수만 읽는지 테스트.
- 웹: 공간 설정(공간 정보·가족·개인정보·외부 서비스·내보내기·삭제·도움 안내), 계정 설정(큰 글씨·쉬어 가기·무료 AI 동의·계정 삭제), 초대 수락, 도움 안내, 개인정보 처리방침 초안.

### 7단계 — 마음 돌봄
- 자살·자해 위험 신호 규칙(사별 상황의 "따라가고 싶어" 포함) + 선택적 LLM 분류(LLM은 위험도를 올리기만 한다). "배고파 죽겠다" 같은 일상 표현은 걸리지 않게 테스트.
- 위험 신호가 보이면 클립보다 먼저 도움 안내(109, 1577-0199, 119)를 띄운다.
- 쉬어 가기 안내(탓하지 않는 말투, 시간 조절·끄기 가능).
- 생일·기일·지난해 오늘 앱 안 알림(P1). 한국 시간 밤 10시~아침 8시에는 새로 띄우지 않는다.
- 클립 모음 API(P1): 그 사람 목소리 클립만 담긴다.

### 8단계 — 샘플·e2e·eval
- 샘플 공간 "[샘플] 김순자 할머니"(가상 인물): 클립 40개 자막 fixture, 사진 placeholder 12장, 'N년 전 오늘' 클립.
- 녹음은 placeholder('샘플 녹음 준비 중'). 팀원 녹음을 fixtures/demo/demo-XX.m4a로 넣으면 make seed가 바꿔 쓴다. 대본: docs/demo-recording-script.md.
- 랜딩에서 가입 없이 샘플 공간과 대화(읽기 전용).
- 골든 세트 30문항 + '맞는 녹음 없음' 4문항, make eval: top-3 정확도 lite 96.7% / kiwi 100%, 없음 판정 4/4 (mock 기준).
- 토크나이저 개선: 조사 뗀 명사는 어미를 더 떼지 않음, 한 글자 명사+조사, 부탁 말투 불용어, 일치도는 대표 낱말로 계산.
- Playwright e2e 4개: 샘플 체험, 가입→업로드→목소리 확인→대화, 미리 남기기(가짜 마이크), 삭제.

### 9단계 — Render 배포 설정
- render.yaml 하나로 PostgreSQL 16 + API(Docker, ffmpeg) + 웹(Node)을 무료 등급으로.
- 무료 등급 맞춤: DB 저장소(암호화), 파일 25MB·공간 150MB 상한, lite 토크나이저(API 최대 메모리 약 166MB 측정), API 안 작업 처리.
- 잠든 서버 대비: 웹 시작 때 API 깨우기(instrumentation), 화면은 JSON 아닌 응답·502·연결 실패면 "서버를 깨우는 중이에요"와 최대 2분 자동 재시도.
- staging: 초대 코드 가입, 사용자별 업로드 300MB·하루 대화 150회 제한, 샘플 체험은 가입 없이.
- 녹음·초대 링크 주소는 YEOUN_PUBLIC_WEB_URL이 없으면 브라우저 주소(Origin)를 쓴다.
