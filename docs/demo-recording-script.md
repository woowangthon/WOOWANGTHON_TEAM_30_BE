# 샘플 목소리 녹음 대본 — [샘플] 김순자 할머니

## 이 문서는 무엇인가요

데모용 샘플 공간 **"[샘플] 김순자 할머니"** 에는 지금 기계음/무음 placeholder 오디오가 들어 있어요.
이 대본은 그 placeholder를 **팀원이 직접 녹음한 목소리로 바꾸기 위한 것**이에요.
실제 녹음처럼 들리면 검색·재생 흐름을 시연하고 테스트하기가 훨씬 좋아집니다.

김순자 할머니는 **가상 인물**입니다. 실제 사람이 아니에요.

- 1941년생, 남쪽 바닷가 마을 출신
- 요리를 좋아하고, 작은 밭을 가꾸고, 트로트를 조금 흥얼거리는 다정한 할머니
- 듣는 사람은 손주 **지은** — 할머니는 "우리 강아지"라고 불러요
- 녹음 출처는 통화 녹음, 동영상, 음성 메시지, 미리 남기기(질문 카드 답변) 네 가지예요

## 녹음 규칙

1. **실존 인물 흉내 금지.** 내 가족, 연예인, 유명인 등 실제 누군가의 목소리나 말투를 따라 하지 마세요. 가상의 '김순자 할머니'를 연기하는 거예요.
2. **대사는 글자 그대로 읽어 주세요.** 검색 평가가 아래 텍스트를 기준으로 하기 때문에 단어를 바꾸거나 빼면 안 돼요. 억양과 사투리 느낌은 자연스럽게 살려도 좋아요.
3. **조용한 곳에서 녹음해 주세요.** 에어컨·TV 소리가 없는 방이면 충분해요. 동영상 장면(바닷가, 부엌 등)도 배경 소리 없이 녹음해도 괜찮아요.
4. **휴대폰 기본 녹음 앱이면 OK.** 입에서 한 뼘(15~20cm) 정도 떨어뜨리고, 바람 소리가 들어가지 않게 해 주세요.
5. **한 줄 = 파일 하나.** 한 파일에 대사 하나만 담아 주세요.
6. **길이는 2~30초.** 앞뒤 무음은 1초 이내로 잘라 주세요.
7. 톤 지시는 참고용이에요. 너무 연기하지 말고, 진짜 할머니가 손주에게 말하듯 편하게 읽어 주세요.

## 파일 이름과 넣는 곳

- 저장 위치: `fixtures/demo/`
- 파일 이름: `demo-01.m4a` … `demo-40.m4a` (아래 표의 번호와 같게)
- 형식: **m4a / mp3 / wav 모두 OK.** 확장자만 다르고 이름(basename)은 같아야 해요. 예) `demo-07.mp3`, `demo-07.wav`
- 같은 번호로는 파일을 하나만 두세요.
- 녹음 파일을 넣은 뒤 아래 명령을 실행하면 seed가 자동으로 찾아서 placeholder를 바꿔 줘요.

```bash
make seed
```

## 개인정보 안내 (꼭 읽어 주세요)

- 팀원의 목소리 녹음도 **개인정보**예요. 녹음하기 전에 읽는 사람 본인의 동의를 받아 주세요.
- 녹음한 사람은 **언제든 삭제를 요청할 수 있어요.** 요청이 오면 해당 파일을 지우고 `make seed`를 다시 실행해 placeholder로 되돌려 주세요.
- 녹음 파일은 데모·테스트 용도로만 쓰고, 다른 곳에 따로 공유하지 마세요.
